# Cópia do jogo

Arquivo de Super Bomberman 5 (Japan) fornecido pelo proprietário e incluído neste backup a pedido dele.

- Arquivo: `super-bomberman-5.sfc`
- Tamanho: 2.097.152 bytes (2 MiB).
- SHA-256: `b8ea7591bd957c67cc27955e00609f1d659db9ac91a9bd321750de2ab4d1d676`.

No GitHub, abra o arquivo e use **Download raw file**. No site, abra **Instalar o jogo neste aparelho** e selecione esse arquivo. Após a primeira importação, a cópia fica no IndexedDB deste navegador.

O arquivo fica fora de `public/`; `.vercelignore` e `.dockerignore` continuam excluindo ROMs do deploy. Esse backup do GitHub não altera o acesso autenticado a `/api/rom` no site publicado.
